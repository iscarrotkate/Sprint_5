# Описание

Данный проект предоставляет автотесты для сервиса Stellar Burgers для сбора и заказа бургеров из необычных ингредиентов.

# Framework
**Selenium WebDriver** - инструмент для автоматизации действий веб-браузера.
**Pytest** - фреймворк для тестирования программного обеспечения на языке Python

# Использование
## Тесты
Директория "tests" содержит автотесты, покрывающие следующий функционал:
### tests/test_authorization.py
Файл содержит тесты, проверяющие авторизацию.
1. **test_open_login_form_by_unauthorized_user **- проверка перехода на страницу авторизации с разных локаций приложения
2. **test_login_with_valid_data** - проверка авторизации существующего пользователя
3. **test_attempt_to_login_with_invalid_data** - проверка попытки авторизации несуществующим пользователем и существующим пользователем с невалидным паролем
4. **test_logout** - проверка выхода из аккаунта

### tests/test_constructor.py
Файл содержит тесты, проверяющие конструктор бургеров
1. **test_navigation_between_constructor_sections** - проверка навигации между вкладками конструктора бургеров

### tests/test_profile.py
Файл содержит тесты, проверяющие личный кабинет
1. **test_open_profile_page_by_authorized_user** - проверка перехода на страницу личного кабинета и релевантности данных пользователя
2. **test_navigate_to_main_page_from_profile** - проверка перехода на главную страницу из личного кабинета

### tests/test_registration.py
Файл содержит тесты, проверяющие регистрацию
1. **test_registration_new_user_valid_data_directed_to_login_page** - проверка регистрации нового пользователя с валидными данными
2. **test_registration_new_user_with_empty_name** - проверка попытки авторизации с пустым именем
3. **test_registration_email_format_validation** - проверка валидации формата email
4. **test_registration_invalid_password_returns_error** - проверка валидации пароля

## Вспомогательные средства
### tools/functions.py
Файл содержит генераторы тестовых данных и вспомогательные методы для использования в автотестах
1. **login_generator** - генерирует валидный  email по заданному шаблону
2. **password_generator** - генерирует валидный пароль из случайного набора цифр
3. **fill_in_registration_form** - заполняет форму регистрации переданными данными
4. **login** - открывает страницу авторизации, осуществляет вход и возвращает на страницу, с которой была вызвана функция

### tools/locators.py
Файл содержит локаторы используемых в тестах элементов
### tools/pages.py
Файл содержит классы, описывающие страницы
### tests/conftest.py
Файл содержит фикстуры, используемые в автотестах
